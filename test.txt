OBJECT ORIENTED PROGRAMMING

It's a way to organize code by grouping related data and functions together. instead of having related variables and functions scattered around, you bundle 
them into objects.


CLASSES  
A class is a blueprint for creating objects. it defines:
Attributes: What data the object stores
Methods: What the object can do.


class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

self refers to the current object.it's how an object keeps track of its own data.
